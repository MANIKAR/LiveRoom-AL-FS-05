## Overview
LiveRoom is a real-time voice collaboration platform where users can join custom rooms (e.g., AL-FS-05) and get live voice transcription. Built as a P2P solution without heavy backend dependency.

## Features
- ✅ Dynamic Room Display - Type room code and UI updates to `Room: <code>` instantly
- ✅ Real-Time Voice Chat via WebRTC (PeerJS)
- ✅ Live Captions / Transcription using Web Speech API
- ✅ Mic Toggle with ● REC indicator
- ✅ Clean, Responsive UI with Tailwind CSS
- ✅ No Backend Needed - Cloud P2P

## Tech Stack
- Frontend: React + Vite
- Styling: Tailwind CSS
- Voice: WebRTC - PeerJS
- Speech: Web Speech API
- Icons: Lucide React
